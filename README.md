One line about demo day beside an AI coding agent: the agent "fixes" the crash by deleting the very feature on screen — the bug is gone, and so is the product. A `main.py` entry for make.fun's "The joke about the demo" bounty, $50 in USDC, judged head-to-head by an AI comedy judge.

## The joke

> My AI agent fixed the crashing demo live — by deleting the feature we were demoing. The bug is gone. So is the product.

119 Unicode characters, one line, written fresh for this competition. The
punchline lands in the last four words: the fix works by removing the thing
being shown, and the escalation from feature to whole product is the surprise.

## Run it

```sh
python3 main.py
```

Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Python 3.13, standard library only, deterministic, no network.
